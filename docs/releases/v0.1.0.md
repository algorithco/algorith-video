# AlgorithVideo 0.1.0

The first AlgorithVideo desktop release by Algorithco turns long videos into captioned short clips, with local rendering and your own AI provider accounts.

## Downloads

| System | Asset |
| --- | --- |
| Windows x64 | `AlgorithVideo-0.1.0-win-x64.exe` |
| macOS Apple Silicon | `AlgorithVideo-0.1.0-mac-arm64.dmg` or `.zip` |
| macOS Intel | `AlgorithVideo-0.1.0-mac-x64.dmg` or `.zip` |
| Linux x64 | `AlgorithVideo-0.1.0-linux-x64.AppImage` or `.deb` |

All installers are built and verified on native GitHub Actions runners. `SHA256SUMS.txt` and `release-manifest.json` identify the exact files and source commit. Native verification reports, dependency inventories and corresponding FFmpeg/library sources accompany the release.

The large Windows/Linux source archive is split into numbered `.partNN` assets. `SOURCE-RECONSTRUCTION.txt` explains how to combine and verify them; installers work independently of these source downloads.

## Included

- Local files, public YouTube videos and completed Twitch VODs.
- Automatic clip selection or a review-and-edit workflow.
- Vertical and horizontal exports, smart framing and caption styles.
- A timeline editor, crop controls, caption editing and Library management.
- Optional assistant chat, Zernio social posting and automation queues.
- Bundled Python, FFmpeg, ffprobe and yt-dlp; no separate development environment is required.

## Before using this release

- This first release has no publisher certificate. Windows and Linux packages are unsigned; macOS apps use ad-hoc signing and are not notarized. Operating systems can display publisher/security warnings. Automatic updates are disabled; download future releases manually.
- AI transcription and planning require an OpenRouter API key with credit. Audio, transcript text and enabled visual samples are sent to providers. Optional social publishing uploads selected clips through Zernio. See the [privacy guide](https://github.com/algorithco/algorith-video/blob/main/docs/ai-and-privacy.md).
- A development-only CSS parser advisory remains in the Tailwind 3 build dependency chain; the incompatible Tailwind 4 migration is tracked separately. Runtime npm dependencies passed the dependency audit at release preparation.
